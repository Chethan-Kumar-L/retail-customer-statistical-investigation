# 📊 Retail Customer Insights & Statistical Investigation

## 🎯 Business Problem
Investigated a retail customer dataset (10,675 rows across ~1,000 unique customers) to uncover spending trends, behavioral signals, and demographic influences.

## 🛠️ Tech Stack & Statistical Tools
* **Language:** Python (`Pandas`, `SciPy`, `Statsmodels`)
* **Descriptive Stats:** Mean, median, standard deviation, and modal distributions.
* **Inferential Statistics:** Independent t-tests, One-way ANOVA, and Correlation Matrices.

## 🧪 Hypothesis Testing & Findings
* **Spending Analysis:** Compared spending behavior across demographics using histograms, boxplots, and KDE plots.
* **Statistical Validation:** Formulated null and alternate hypotheses, tested assumptions (normality, variance), and interpreted p-values to determine if education levels or geography significantly impact monthly spend.
